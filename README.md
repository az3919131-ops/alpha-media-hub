# Alpha Media Hub

منصة نشر الفيديو لقناة **Alpha Media** على يوتيوب ([@alphamedia-010](https://youtube.com/@alphamedia-010)).

- **الصفحة الرئيسية** `/` تعرض أحدث فيديوهات القناة.
- **لوحة التحكم** `/dashboard.html`:
  - فيديوهات القناة، مع زر نشر كل فيديو على المنصات
  - رفع فيديو من الجهاز مباشرة إلى يوتيوب (Google OAuth) أو مشاركة رابط
  - المنصات: فيسبوك وإنستاجرام وتيك توك ولينكد إن وX، وأي منصة إضافية عبر Webhook / API
  - سجل النشر، والإعدادات، ودليل الربط
- **مراقبة تلقائية**: دالة مجدولة تفحص القناة كل 10 دقائق وترسل أي فيديو جديد إلى المنصات المفعّلة عبر Zapier / n8n / Make / Webhook.

## الإعداد على Netlify

| المتغير | الوصف |
|---|---|
| `ADMIN_KEY` | مفتاح الدخول إلى لوحة التحكم (إلزامي) |

بقية الإعدادات (روابط Zapier، المنصات، Google Client ID) تُضبط من لوحة التحكم وتُحفظ في Netlify Blobs، فتظهر من أي جهاز.

## البنية

```
public/                 الواجهة (HTML/CSS/JS ثابتة)
netlify/functions/      واجهات API والدالة المجدولة youtube-watch
netlify/lib/core.mts    التخزين، قراءة قناة يوتيوب، التوزيع على المنصات
```
