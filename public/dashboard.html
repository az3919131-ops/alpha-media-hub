دليل الربط

خطوات ربط المنصة بحساباتك مرة واحدة.

ربط Zapier (فيسبوك، إنستاجرام، تيك توك، لينكد إن)

  1. في Zapier أنشئ Zap جديدًا، واختر المشغّل Webhooks by Zapier ← Catch Hook، وانسخ الرابط.
  2. الصق الرابط في المنصات ← رابط Zapier الرئيسي واحفظ، ثم اضغط اختبار على أي منصة ليصل مثال للبيانات.
  3. أضف خطوة Paths بشرط platform_kind يساوي facebook أو instagram أو tiktok أو linkedin.
  4. في كل مسار أضف إجراء النشر: Facebook Pages ← Create Page Post لصفحة Alpha Media، وInstagram for Business، وTikTok، وLinkedIn ← Create Company Update. استخدم caption للنص وvideo_url للرابط.
  5. شغّل الـ Zap. من الآن أي فيديو جديد يُنشر وحده.

تفضّل Zap منفصلًا لكل منصة؟ ضع رابط Catch Hook الخاص بها في خانة Webhook داخل صف المنصة.

ربط n8n أو Make

  1. في n8n أضف عقدة Webhook بطريقة POST وفعّل الـ workflow.
  2. انسخ Production URL وضعه في خانة Webhook للمنصة، واختر نوع الربط n8n.
  3. أضف بعدها عقدة Switch على {{$json.body.platform_kind}} ثم عقد النشر لكل منصة.

أي خدمة أخرى تقبل طلب POST بصيغة JSON تعمل بنفس الطريقة. إذا كانت تتطلب مفتاح API ضعه في خانة «توكن»، ويُرسل كـ Authorization: Bearer.
